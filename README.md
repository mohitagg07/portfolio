# Mohit Aggarwal Portfolio

A portfolio for Mohit Aggarwal, an AI and automation developer based in Jammu, India. Built with Next.js 16, React 19, TypeScript, and Tailwind CSS 4.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## YouTube videos

The “Outside of work” section shows recent videos from the channel feed. Set `YOUTUBE_API_KEY` in `.env.local` to enable subscriber and view counts; if the Data API is unavailable, recent videos still load through the public channel feed.

The Open Graph and Twitter preview image is generated by Next.js. Set `NEXT_PUBLIC_SITE_URL` to the deployed site’s full origin when hosting outside Vercel so social image URLs resolve to the public domain.

## Portfolio content

- Project descriptions and demo URLs: `app/components/Projects.tsx`
- Social links and contact email: `app/components/ContactSection.tsx`
- About content: `app/components/Story.tsx`
- Images: `public/projects/` and `public/assets/`
- Search and social metadata: `app/layout.tsx`

## Deploy

Deploy the repository with Vercel or another Next.js host. Configure `YOUTUBE_API_KEY` in the deployment environment to show subscriber and view counts.
